# Dbms_project
Government Welfare Scheme  Management System 

Application Domain 

This project falls under Public Administration & Social Welfare, focusing 
on digital governance (e-Governance) of social welfare schemes. The 
objective is to ensure that government resources reach eligible 
beneficiaries accurately, efficiently, and transparently through a centralized 
database system.
